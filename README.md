#RFID-Based Access Control System

The **Keyless Guardian 2.0)** is an advanced RFID-based access control system designed for secure and reliable door management in restricted environments. It uses an ESP32 for parallel card scanning, improved detection, and local storage of authorized users via SPIFFS, ensuring operation even without Wi-Fi, with automatic cloud synchronization when connectivity is restored.

The system features an Admin mode with an OLED display for onboard control, along with real-time monitoring through a Next.js dashboard with secure authentication. It integrates Discord API alerts and a camera feed for enhanced security and access tracking.

Built with two custom PCBs (indoor and outdoor units), the system includes safety features like emergency power input and a DIY BMS for backup. The enclosure is designed in Fusion 360 for a compact and professional finish, making it a robust and scalable solution for modern access control.
